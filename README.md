# ForgePC — 3D PC Builder

A zero-build tool to design a PC in real 3D with live UAE retail prices. Drag to orbit, scroll to zoom, click any part to inspect it, and get a compatibility-checked build with share links and screenshots.

## Quick start

```bash
npm install      # no runtime deps — only for convenience (empty)
npm start        # http://localhost:5173/
```

No build step, no frameworks. Everything is static files served by a small Node HTTP server (`server.mjs`).

```bash
npm start -- 8000   # or: PORT=8000 npm start
```

## Scripts

| Command | What it does |
| --- | --- |
| `npm start` | Run the static server (default port 5173). |
| `npm test` | Run the Node test suite (`node --test`). |
| `npm run lint` | Syntax-check every JS file (`node --check`). |
| `npm run sync-prices` | Scrape retailer price caches into `price-cache.json`. |

## Testing

- **Unit/integration** — `npm test` runs `tests/*.test.mjs`: part schema/uniqueness, compatibility rules, power estimation, seeded random builds, build serialization, and store round-trips.
- **Browser smoke** — boots the app in headless Edge via CDP and exercises picking (through glass), currency/VAT/language switches, the hover tooltip, screenshots and the share toast:

  ```bash
  node server.mjs 5173 &
  node tests/smoke.mjs http://localhost:5173/ 9333   # 9333 = --remote-debugging-port
  # uses Edge at C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
  ```

## URL parameters

| Param | Effect |
| --- | --- |
| `?seed=<n>` | Deterministic showcase build for a seed. |
| `?build=<base64url>` | Restore a saved build from a Share link. |
| `?outline=0` | Disable the selection outline (low-end machines). |
| `?low=1` | Force the low-end preset (render pixel ratio 1 + outline off). |

## Where prices come from

Catalog prices in `js/data/parts.js` are hand-set **AED retail estimates (VAT included)**. `npm run sync-prices` can overlay fresher figures into `price-cache.json` (written by `js/update-prices.mjs`), which the server serves at `/api/prices`. Without a cache, the UI shows "Prices: AED estimates". The shop lists in the sidebar are generated by `js/retailers.js`.

Currency (AED/USD/EUR) and vend-excluded VAT view toggle are persisted in `localStorage` (`forgepc-settings`), as is your in-progress build (`forgepc-build`).

## Architecture

```
forge-pcbuilder/
├── index.html            # single-page shell (tabs, toolbar, summaries, PWA manifest)
├── css/styles.css         # themes + responsive breakpoints (1180/960/680px, RTL)
├── js/
│   ├── main.js            # boot: restore build (?build= → localStorage → seed), autosave, SW
│   ├── ui.js              # all DOM rendering: tabs, lists, compare, summary, buy, HUD, toasts
│   ├── scene.js           # THREE.Viewer: renderer, camera, picking, hover, screenshot, fans
│   ├── models.js          # parametric part geometry + shared material cache (LAYOUT in cm)
│   ├── build.js           # BuildStore (state/compat/power) + encodeBuild/decodeBuild
│   ├── boutique modules   # settings.js, i18n.js (EN/AR + RTL), currency.js, prices.js, retailers.js
│   ├── data/parts.js      # 105-part catalog across 8 categories
│   └── data/rules.js      # compatibility checks + power estimation
├── vendor/                # Three.js r160 + OrbitControls, RoomEnvironment, post-processing
├── server.mjs             # static server: gzip/brotli, ETags/304, /api/prices, traversal guard
├── service-worker.js      # offline shell (network-first HTML, cache-first assets, never /api)
├── manifest.json + icons/ # installable-PWA assets
└── tests/                 # node:test suites + headless CDP smoke
```

## Orientation

The virtual case is centered on the origin with coordinates in centimeters: open/camera side is +X, motherboard tray side −X, front +Z, rear −Z (`LAYOUT` in `js/models.js`).

## PWA

`service-worker.js` enables offline serving and installability on `localhost` and HTTPS. The manifest + 192/512 icons allow "Install app" in Edge/Chrome.
